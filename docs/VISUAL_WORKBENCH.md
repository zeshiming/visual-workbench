# AI 图片创作工作台：项目改造记录

## 项目定位

基于 Doushabao 的图片编辑工作台，逐步加入可独立使用的照片整理、AI 生图、AI 写真、AI 电商图与分镜创作入口。视频中的摄影软件只作为流程参考，并非本项目代码来源。

## 已完成：项目素材库

- 一个项目可以保存多张 JPEG、PNG 或 WebP 素材；单张上限 20 MB。
- 在编辑界面批量导入图片、切换当前编辑图片、保存当前结果、从素材库移除图片。
- 图片原文件存于服务端，元数据存于 SQLite；删除项目时清理所属素材。
- 保留原有单图 AI 修图与局部编辑流程，后续模块可共用素材库。

核心接口：`GET/POST /api/v1/workspaces/{id}/assets`、`GET /api/v1/workspaces/{id}/assets/{assetId}/image`、`DELETE /api/v1/workspaces/{id}/assets/{assetId}`。

## 后续迭代

1. **照片整理**：从 Photo Curator 拆出模糊与相似图筛选逻辑，接入项目素材库，并记录人工改选。
2. **AI 生图**：新建独立的文字生图入口，支持参考图、模型任务状态与版本记录。
3. **场景化入口**：写真和电商图复用生图与编辑能力，增加各自的约束和质量检查。
4. **分镜**：以场景、镜头、角色为结构生成多张图，逐格重试并检查连续性。
5. **Agent 评测**：记录计划、工具调用、结果、人工修改、耗时与成本；建立固定图片集评估质量。

## 当前边界

Doushabao 原有 Agent 为分析后编辑的两步流程。照片整理、生图、写真、电商图、分镜和结果复查尚未实现，不能作为已完成经历写入简历。图片模型调用依赖用户配置兼容的服务和密钥。
